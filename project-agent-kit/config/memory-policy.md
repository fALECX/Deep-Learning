# Memory policy

Native memory is the scratchpad. Checked-in instruction files are the contract.

1. Let Claude or Codex retain observations in their native memory system.
2. Detect repeated corrections or durable repository facts.
3. Propose a small promotion with evidence and show the diff.
4. Promote only after user approval.

This prevents an agent from silently rewriting project behavior based on a single frustrated message, temporary task, or sensitive detail.
